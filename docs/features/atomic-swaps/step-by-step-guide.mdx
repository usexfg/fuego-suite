This page is a compact CLI walkthrough. The flow is the same for ETH, SOL, XMR, BCH, and other configured pairs.

## Prerequisites

- `fuegod` running and synced
- Counterparty chain RPC running and synced (for the pair)
- **`xfg-swapd`** with configs from `scripts/templates/swap-config-*.json.example`
- XFG in your Fuego wallet (Bob) and CTR funds on the acceptor side (Alice)
- Optional: `./scripts/when-testnet-ready.sh` soft checklist

## Initiate the swap (Bob)

```bash
xfg-swapd --testnet \
  --fuegod-host 127.0.0.1 --fuegod-port 28280 \
  --data-dir /tmp/xfg-swapd-bob \
  --swap-config scripts/templates/swap-config-bob.json \
  initiate ETH 10000000 1000000000000000 127.0.0.1:18911
```

Usage:

```text
xfg-swapd initiate <pair> <xfg_amount> <ctr_amount> <peer>
```

- Amounts are **atomic integers** (`1 XFG = 10_000_000`)
- `peer` is Alice’s swap P2P endpoint (`host:port`)
- Save the **swap id** for accept / status / refund

## Accept (Alice)

```bash
xfg-swapd --testnet \
  --fuegod-host 127.0.0.1 --fuegod-port 28280 \
  --data-dir /tmp/xfg-swapd-alice \
  --swap-config scripts/templates/swap-config-alice.json \
  accept <swap_id>
```

Keep both daemons in **`--service`** mode so fund-escrow, lock, and claim ticks run.

## Monitor swap progress

```bash
xfg-swapd --testnet --data-dir /tmp/xfg-swapd-bob \
  --swap-config scripts/templates/swap-config-bob.json list

xfg-swapd --testnet --data-dir /tmp/xfg-swapd-bob \
  --swap-config scripts/templates/swap-config-bob.json status <swap_id>
```

## Swap state progression

<Steps>
  <Step title="Keys exchanged">
    Both daemons exchange adaptor public keys. State: `ADAPTOR_KEYS_EXCHANGED`.
  </Step>
  <Step title="Escrow funded">
    XFG is locked in the MuSig2 / time-locked escrow. State: `ADAPTOR_ESCROW_FUNDED`.
  </Step>
  <Step title="Pre-signatures ready">
    Parties prepare adaptor-signed material. State: `ADAPTOR_PRESIGS_READY`.
  </Step>
  <Step title="Alice locks CTR">
    Counterparty HTLC locked with \(H(t)\). State: `ADAPTOR_CTR_LOCKED`.
  </Step>
  <Step title="Secret revealed">
    Bob claims CTR with preimage \(t\); Alice extracts \(t\). State: `ADAPTOR_SECRET_REVEALED`.
  </Step>
  <Step title="Complete or refund">
    Success: `ADAPTOR_XFG_SPENT`. Timeout path: `ADAPTOR_REFUNDED`.

    XFG-side protocol fees feed **HEAT CDs** (majority) and treasury (minority) — **not** Hearth’s 0.3% LP fees.
  </Step>
</Steps>

## If the counterparty disappears

After the timelock expires:

```bash
xfg-swapd ... refund <swap_id>
```

Do not refund before expiry — the daemon will reject early attempts. Check `status` for timeout height.

## After the swap

Confirm wallet balances. Run `list` to see history of completed and refunded swaps. For soft vs AFK offers, bridges, and Hearth connectivity, use the [unified user guide](/tutorials/swapxfg-and-hearth-user-guide).
