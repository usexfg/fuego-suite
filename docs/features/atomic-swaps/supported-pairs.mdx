## Available pairs

| Pair | Counterparty chain | Daemon |
|------|--------------------|--------|
| XFG ↔ XMR | Monero | **`xfg-swapd`** (unified) |
| XFG ↔ ETH | Ethereum | **`xfg-swapd`** |
| XFG ↔ SOL | Solana | **`xfg-swapd`** |
| XFG ↔ BCH | Bitcoin Cash | **`xfg-swapd`** |
| XFG ↔ ARB / BASE | Arbitrum / Base (EVM) | **`xfg-swapd`** where configured |

One daemon, pair selected at `initiate` / in config. Older docs naming `xfg-xmr-swap` (etc.) are obsolete.

## On-chain price discovery

XFG also has on-chain swaps for price discovery. These operate within the Fuego chain itself and feed into the fee pool. Cross-chain swaps (the table above) use adaptor signatures with the counterparty chain's native transaction format.

## Running a swap daemon

Start **`xfg-swapd`** alongside `fuegod` with a swap-config that fills the pair’s RPC fields:

```bash
# Service mode — see scripts/when-testnet-ready.sh for dual Alice/Bob ports
./xfg-swapd --testnet \
  --fuegod-host 127.0.0.1 --fuegod-port 28280 \
  --data-dir ~/.xfg-swapd \
  --swap-config scripts/templates/swap-config-bob.json \
  --status-port 18900 --swap-p2p-port 18901 --swap-p2p-bind 127.0.0.1 \
  --service
```

Configs: `scripts/templates/swap-config-*.json.example`. Full walkthrough: [user guide](/tutorials/swapxfg-and-hearth-user-guide).

## Confirmation requirements

Confirmation counts vary by chain to account for different reorganization risks:

| Chain | Typical confirmations |
|-------|-----------------------|
| XFG | 10 blocks |
| XMR | 10 blocks |
| ETH | 30 blocks |
| SOL | Finalized slot |
| BCH | 6 blocks |

These values may be configurable in the swap daemon — check the daemon's `--help` output for your pair.

## Alias support

CLI initiate uses peer endpoint + pair label (not only aliases):

```bash
xfg-swapd initiate XMR <xfg_atomic> <ctr_atomic> 127.0.0.1:18911
```

The **swapxfg** TUI also supports alias-style initiate where configured — see [user guide](/tutorials/swapxfg-and-hearth-user-guide) and `swapxfg/README.md`.
