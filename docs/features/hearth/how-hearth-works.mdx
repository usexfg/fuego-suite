**Hearth** is Fuego’s native **XFG/HEAT** exchange: a constant-product AMM with orderbook / depth-band machinery (pool orders, adaptive spread). It is the price surface for minting HEAT and for on-chain XFG↔HEAT swaps.

## What Hearth is not

- Not a centralized order book hosted by a company
- Not the same as **swapXFG** (cross-chain atomic swaps)
- Not DIGM

## Fee (live code)

| Constant | Value |
|----------|-------|
| `HEARTH_FEE_BPS` | **100** = **1.0%** of trade notional → **CD yield pool** |

```
totalFee = amount × HEARTH_FEE_BPS / 10000   // → CD yield pool
spreadReward = |fill.price − P_clear| × amount  // → LP reserves (LP income)
```

There is **no** separate “0.3% Hearth LP fee” in `CryptoNoteConfig.h`. LPs earn the **swap spread**, not the flat fee. (Adaptive **spread** for pool orders uses other BPS constants, e.g. base spread 30 bps — that market-making width is the LP's income source.)

## Roles

| Role | Action |
|------|--------|
| Trader | Swap XFG↔HEAT; pays 1% flat fee |
| LP | Provides XFG/HEAT liquidity; earns the **swap spread** (`|fill.price − P_clear| × amount`), auto-compounded into reserves — not the flat fee |
| Minter | Uses Hearth TWAP when burning XFG to mint HEAT |
| CD holder | Receives the 1% Hearth flat fee via yield plumbing |

## Privacy

LP and commitment-style positions use the chain’s commitment / privacy primitives. Exact share sizes are not meant to be public account balances like a CEX.
