---
title: "Burn-to-mint"
description: "Why Fuego uses burn-to-mint for HEAT instead of free minting."
keywords: ["burn2mint", "HEAT", "deflation"]
---

Fuego mints HEAT only when XFG is burned. That couples:

- **Scarcity pressure** on XFG (deflationary path / Eternal Flame share)
- **Issuance** of the purchasing-power asset HEAT

No unbounded “print HEAT” path for yield. CD yield is funded by **real protocol fees** (atomic-swap activity), not emissions.

Full economics: [HEAT overview](/heat/overview).
