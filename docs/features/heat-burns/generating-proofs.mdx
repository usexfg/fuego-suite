Earlier designs used external **STARK-style proofs** for burns. That path is **deprecated**.

Current burn-to-mint is **native** to Fuego consensus/wallet flows. Prefer [What are burns](/features/heat-burns/what-are-burns) and [HEAT overview](/heat/overview).
