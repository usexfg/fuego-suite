## Usage Examples

### Example 1: Twitter Announcement
```bash
# Generate hero image
stability-ai generate \
  --prompt "FUEGO XFG cryptocurrency logo, stylized flame, 
  dark obsidian background, orange fire glow, 4k" \
  --style digital-art \
  --aspect-ratio 16:9
```

### Example 2: Instagram Feature
```bash
# Generate privacy graphic
ai-studio-image \
  --template "instagram-lifestyle" \
  --customization "cryptocurrency privacy shield, 
  flame patterns, dark moody atmosphere"
```

### Example 3: Discord Emote
```bash
# Generate small flame icon
stability-ai generate \
  --prompt "minimalist flame icon, XFG symbol, 
  transparent background, orange glow, simple" \
  --aspect-ratio 1:1 \
  --style None
```

## Batch Processing

For campaign consistency, generate base images then customize:

1. **Base:** Dark background with subtle fire particles
2. **Layer 1:** XFG coin or logo overlay
3. **Layer 2:** Platform-specific text/branding
4. **Layer 3:** Platform-specific dimensions

This ensures visual consistency across all channels.
