## Visual Elements

### Logo
- **Primary:** "Fuego" text with flame motif
- **Symbol:** Fire/Flame icon
- **XFG:** Coin token symbol
- **Colors:** Orange gradient on dark background

### Imagery Style
1. **Dark/Cinematic:** Deep blacks, dramatic lighting
2. **Fire/Flame motifs:** Orange-red gradients
3. **Privacy themes:** Hoods, masks, digital elements
4. **Freedom symbolism:** Open doors, keys, unchained

### Iconography
- **Style:** Minimal line icons
- **Stroke:** 2px consistent
- **Corner radius:** 4px
- **Primary color:** Orange or Smoke blue

---

## Design Principles

1. **Dramatic Contrast** - Light on dark, flame colors against black
2. **Minimalist** - Less is more, clean layouts
3. **Crypto-Native** - Digital aesthetic, block elements
4. **Privacy-First** - Mysterious, protected imagery
5. **Fire Motifs** - Subtle flame integration in key visuals

## Application Examples

### Social Media
- **Twitter/Instagram:** Dark background, flame accents
- **Discord:** Orange highlights on dark

### Website
- **Hero:** Full-width dramatic imagery
- **Cards:** Subtle glow effects on hover
- **CTAs:** Orange with subtle gradient

### Print
- **Business cards:** Black with orange emboss
- **Event banners:** High contrast fire imagery

---

## Do's and Don'ts

### Do
- ✓ Use dark backgrounds with fire accents
- ✓ Include flame/fire elements subtly
- ✓ Show privacy and freedom themes
- ✓ Use dramatic lighting
- ✓ Keep layouts clean and minimal

### Don't
- ✗ Use bright, saturated backgrounds
- ✗ Add unnecessary text or clutter
- ✗ Mix with competing brand colors
- ✗ Use cartoonish or playful imagery
- ✗ Over-complicate layouts
