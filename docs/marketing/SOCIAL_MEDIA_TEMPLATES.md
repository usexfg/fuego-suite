## Export Settings

### PNG Export
- Color Profile: sRGB
- Bit Depth: 8-bit
- Compression: None (lossless)

### JPG Export
- Quality: 85-90%
- Color Profile: sRGB
- Progressive: Yes

### GIF Export (Animated)
- Color: 256 (optimized)
- Dither: Floyd-Steinberg
- Frame Rate: 15-24 fps

## File Naming Convention

```
fuego_[platform]_[content-type]_[variant]_[date].png

Examples:
fuego_twitter_post_fire-coin_20260426.png
fuego_instagram_story_cd-yield_20260426.png
fuego_discord_banner_community_20260426.png
fuego_youtube_thumb_privacy_20260426.png
```
