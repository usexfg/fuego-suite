# PEG-Q — Quarterly CPI Peg for HEAT (V13)

Status: planned. Supersedes the backlog item "Quarterly CPI mechanism — scheduled peg table + governance process" — replaced by a governance-free, stake-free design.

## Design decisions (final)

| Decision | Value |
|---|---|
| Peg base | Dec-2008 CPI-U NSA = 211.398 (Q4-2008 anchor, closest to Jan-2009) |
| Launch value | $1.574 (Jul-2026 CPI 332.813 / 211.398) |
| Value source | BLS v2 API only (`CUUR0000SA0`) |
| Validator | Truflation US YoY rate (independent methodology) |
| Comparison unit | YoY % — the only unit both sources share (index levels sit on different bases) |
| Band | \|BLS_YoY − Truflation_YoY\| ≤ 2.50pp → apply; otherwise freeze |
| Truflation down | Apply BLS anyway, flag `unvalidated` (silence ≠ evidence of bullshit) |
| Ingest | zkTLS proofs (client-side proof of real TLS session), permissionless reporters |
| Stakes / committees | None. Lying is cryptographically impossible, not economically punished |
| Cadence | Quarterly = 18 epochs = 16,200 blocks = 90 days |
| Activation | `BLOCK_MAJOR_VERSION_13` (V12 is HEAT CDs) |
| Governance | None. Freeze + statement are consensus-computed, deterministic |

## Rules

```
B = BLS YoY % for latest complete quarter (from proof)
T = Truflation US YoY % (from proof)

T missing                  → APPLY(BLS), status APPLIED_UNVALIDATED
|B − T| ≤ 2.50pp           → APPLY(BLS), status APPLIED
|B − T| > 2.50pp           → FREEZE_CONTRADICTION + statement
B missing                  → FREEZE_NO_DATA
```

- First valid proof per (source, quarter) in canonical chain order binds; later proofs for the same (source, quarter) are rejected — revision-proof, reorg-safe.
- Freeze never moves the peg; it only stalls it. Ambiguity means no change, retry next window.
- Statement is generated by the same pure function on every node; no human in the loop.

## Residual trust (stated)

- Trusted: BLS publishing one canonical number (unavoidable); the zkTLS circuit + verifier (needs one audit).
- Not trusted: any reporter, any oracle committee, FRED (dropped — mirror redundancy traded for methodology diversity).

struct CpiPegState {
  enum class Status : uint8_t {
    GENESIS = 0, APPLIED, APPLIED_UNVALIDATED,

  uint64_t pegScaled = 15740;

Fee ≥ `MINIMUM_FEE`; size ≤ 4,096 B; valid only ≥ V13.

## Consensus flow

```
per push (after epoch logic, Blockchain.cpp:~5128):
  if height == W_start(q) + CPI_PROOF_WINDOW_BLOCKS:
      aggregate quarter q−1 from canonical proof txs (see Rules)
      write m_cpiPeg, serialize

per pop (Blockchain.cpp:5726/5877):
  recompute state from remaining chain txs (same pattern as epoch pops)
```

## zkTLS notes

- Vendor a constant-time BN254 Groth16 verifier (~2–3k LOC; adapt gnark's exported C verifier or snarkjs portable). No hand-rolled pairings.
- Circuit pinned at build time; vk is a compile-time constant.
- ~1–2 ms per proof; cap 4 proofs/block.
- Prover side (Go) does real TLS sessions to `api.bls.gov/v2` and `api.truflation.com`; WebProof/TLSNotary-family client proving.

## Risks

| Risk | Mitigation |
|---|---|
| Truflation outage | Apply-with-flag rule (no liveness dependency) |
| BLS revision | First-proof-binds rule; revisions hit next window |
| zkTLS prover breakage | Peg freezes (FREEZE_NO_DATA); prover is bundled open tooling |
| Consensus nondeterminism | Pure functions over canonical txs only; no wall clock/network in consensus path |
| Verifier bug | Audit gate + simnet year-run before activation |
