This short path covers an XFG ↔ XMR (or other pair) atomic swap with the modern daemon.

## Prerequisites

**Both parties:**
- Running and synced node for their chain

**XFG side (you):**
- `fuegod` synced
- **`xfg-swapd`** with a filled swap-config (see `scripts/templates/swap-config-*.json.example`)
- XFG balance to swap; wallet RPC reachable from the config

**Counterparty chain:**
- Synced RPC (e.g. monerod + wallet for XMR) configured in Alice/Bob JSON
- Matching `xfg-swapd` peer online on the swap P2P port

## Dual daemon reference

Local testnet defaults and initiate/accept examples:

```bash
./scripts/when-testnet-ready.sh
```

Bob (initiator) / Alice (acceptor) service mode:

```bash
# Bob
xfg-swapd --testnet \
  --fuegod-host 127.0.0.1 --fuegod-port 28280 \
  --data-dir /tmp/xfg-swapd-bob \
  --swap-config scripts/templates/swap-config-bob.json \
  --status-port 18900 --swap-p2p-port 18901 --swap-p2p-bind 127.0.0.1 \
  --service

# Alice
xfg-swapd --testnet \
  --fuegod-host 127.0.0.1 --fuegod-port 28280 \
  --data-dir /tmp/xfg-swapd-alice \
  --swap-config scripts/templates/swap-config-alice.json \
  --status-port 18910 --swap-p2p-port 18911 --swap-p2p-bind 127.0.0.1 \
  --service
```

## Initiate (Bob) and accept (Alice)

Amounts are **atomic** (`1 XFG = 10_000_000`):

```bash
xfg-swapd --testnet \
  --fuegod-host 127.0.0.1 --fuegod-port 28280 \
  --data-dir /tmp/xfg-swapd-bob \
  --swap-config scripts/templates/swap-config-bob.json \
  initiate XMR <xfg_atomic> <xmr_atomic> 127.0.0.1:18911

xfg-swapd --testnet \
  --data-dir /tmp/xfg-swapd-alice \
  --swap-config scripts/templates/swap-config-alice.json \
  accept <swap_id>
```

## Monitor progress

```bash
xfg-swapd --testnet --data-dir /tmp/xfg-swapd-bob \
  --swap-config scripts/templates/swap-config-bob.json list

xfg-swapd --testnet --data-dir /tmp/xfg-swapd-bob \
  --swap-config scripts/templates/swap-config-bob.json status <swap_id>
```

States progress from `ADAPTOR_KEYS_EXCHANGED` through escrow / CTR lock to `ADAPTOR_XFG_SPENT` or `ADAPTOR_REFUNDED`. Full ladder: [how swaps work](/features/atomic-swaps/how-swaps-work).

## Successful completion

State reaches `ADAPTOR_XFG_SPENT`. XFG-side protocol fees fund **HEAT CD yield** (majority) and treasury (minority) — **not** Hearth LP fees.

## If the counterparty goes offline

Wait for the timelock, then:

```bash
xfg-swapd ... refund <swap_id>
```

Your XFG is returned. No partial exchange occurs.

## Troubleshooting

**Stuck at `ADAPTOR_KEYS_EXCHANGED`** — peer offline or wrong P2P endpoint; wait for timelock and refund if needed.

**Cannot query counterparty height** — fill the pair’s RPC fields in swap-config.

**Daemon restart** — state is persisted; run `list` to resume.
