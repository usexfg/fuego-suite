description: "Cross-chain atomic swaps with the 1% XFG fee split."

1. Run synced Fuego node + SwapDaemon for your pair.
2. Initiate swap; save swap id.
3. Monitor until complete or refund after timelock.
4. On success, **1%** of XFG is protocol fee → **80/20** at v11+ (CD / Bonus Vault); pre-v11 blocks replay 69/11/20.

Details: [How swaps work](/features/atomic-swaps/how-swaps-work), [Supported pairs](/features/atomic-swaps/supported-pairs).
